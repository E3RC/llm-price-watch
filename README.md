# LLM Price Watch

Public daily market watch for coding/agent LLM pricing and access.

Site: https://e3rc.github.io/llm-price-watch/

The daily report compares:

- OpenCode Go and Zen
- OpenRouter and provider-specific routing
- Microsoft Azure AI Foundry
- Direct Chinese/global model vendors
- Free/preview endpoints and promotional access
- Low-cost coding/agent subscriptions
- New model releases

## Publishing

Daily reports are Jekyll posts stored in `_posts/` and published with GitHub Pages from the `main` branch root.

## Access classification

The watch distinguishes general API access, OpenAI-compatible API access, agent/CLI-only access, hosted chat, specific-client-only plans, Azure serverless APIs, Azure managed compute, and Azure provisioned throughput.

See the site Methodology page for details.
